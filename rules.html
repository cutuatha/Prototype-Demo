Important distinction

This registry is the canonical coded record of design decisions. “Approved design” means the rule has been agreed; it does not mean the behavior is already implemented or tested. Implementation status is shown separately. This page does not connect to a live vehicle-history service or verify real listings.

Local decision event log

Events recorded by game pages in this browser appear here. This log is device/browser-specific; the canonical rules themselves are stored in the deployed code. Clearing browser data can erase local events but does not change the registry.
