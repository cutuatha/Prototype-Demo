Setup instructions

1. Search live truck listings

Price range is the primary search criterion. A maximum price is required; minimum, manufacturers, model, sleeper preference, and search area are optional filters.

Manufacturers (optional, select any)

Leave all unchecked to search every manufacturer.

Live results, when connected, appear inside the game. Search results are not a guaranteed inventory feed. Open the original seller page to verify asking price, auction status, availability, mileage, condition, seller, and location.

2. Add a listing to compare

Open a marketplace listing, then enter its details here. IDs are assigned by Prototype; the source URL keeps the original listing handy.

3. Compare and select

Use “Compare to Others” to mark options for comparison. “Select Now” only asks you to confirm which truck to carry forward as selected for planning. It does not authorize purchase, financing, funds commitment, or acquisition.
